# GameLife

Русскоязычный текстовый симулятор жизни: персонаж живет от рождения до смерти, каждый год принимает решения и сталкивается со случайными событиями. Проект развивает жанр life simulator, но не копирует BitLife дословно в бренде, текстах, интерфейсе, названиях или уникальных элементах.

## Запуск

Откройте `index.html` в браузере. Игра начинается с отдельного экрана создания персонажа или кнопки `Случайная жизнь`. Проект подключает обычные статические `.js`-файлы без сборщика и сервера.

## Архитектура

- `game.js` - тонкая точка входа: связывает UI, симуляцию, сохранения и первый рендер.
- `state.js` - состояние новой жизни, нормализация сохранений, общие селекторы и базовые операции над состоянием.
- `data/` - игровые каталоги: страны, имена, профессии, навыки, жилье, вещи, бюджетные режимы, стартовые параметры персонажа, действия отношений и правила итогов жизни.
- `engine/simulation.js` - годовая симуляция: взросление, расходы, налоги, активы, бизнес, естественные изменения.
- `engine/actions.js` - действия игрока: учеба, работа, семья, отношения, деньги, документы, активы и бизнес.
- `engine/npcFactory.js` - создание и нормализация NPC: семья, партнеры, дети, друзья, коллеги и другие связи.
- `engine/relationshipEngine.js` - единая модель отношений, миграция старой семьи в `state.npcs`, ежегодное изменение связей и смерть NPC.
- `engine/relationshipActions.js` - применение data-driven действий отношений из `data/relationshipActions.js`.
- `data/careerEducation.js` - уровни образования, отрасли и каталог конкретных должностей.
- `engine/careerEngine.js` - требования к работам, обучение, собеседования, найм, зарплата, повышение, увольнение, выгорание и годовая карьерная динамика.
- `data/economy.js` - налоговые ставки, типы кредитов, правила активов, недвижимости и расходов.
- `engine/economyEngine.js` - нормализованные финансы, годовые расходы, доходы, кредиты, активы, недвижимость, налоги и финансовая история.
- `engine/events.js` - фасад случайных событий для годового цикла.
- `engine/events/` - проверка условий, расчет весов, применение эффектов и выбор события.
- `ui/render.js` - построение DOM и вызовы engine-функций из кнопок.
- `storage/saveLoad.js` - сохранение, загрузка и сброс игры через `localStorage`.
- `utils/random.js` - базовые случайные и числовые помощники.

## Интерфейс

UI построен mobile-first: на телефоне основные разделы доступны через нижнюю навигацию `Жизнь`, `Действия`, `Отношения`, `Карьера`, `Деньги`, `Здоровье`, `Сводка`, а дополнительные разделы остаются в верхнем горизонтальном списке. На планшете и desktop сетки расширяются без изменения игровой логики.

События показываются как модальные карточки поверх текущего экрана. Журнал жизни, финансовая история, лечение и правовой статус отображаются как timeline. Визуальные состояния `успех`, `риск`, `опасность`, `важное событие`, `смерть` и `достижение` задаются CSS-классами и определяются UI-слоем по тексту события или карточки.

Тема переключается кнопкой в верхней панели и сохраняется в `localStorage` как `gamelife-ui-theme`. Темная тема меняет только визуальные токены CSS и не влияет на сохранения игры.

## План развития

1. Добавить новые категории событий: бизнес, документы, пожилой возраст, наследие.
2. Расширить версионирование сохранений и миграции старых сейвов.
3. Увеличить покрытие тестами годовой симуляции и смерти.
4. Постепенно вынести оставшиеся UI-обработчики, которые меняют состояние напрямую, в `engine/actions.js`.
5. Расширять игровые системы только через каталоги данных и engine-функции.

## NPC, Отношения И Семья

Новая семейная модель хранится в `state.npcs`. Каждый NPC имеет полный набор полей: `id`, `name`, `lastName`, `gender`, `age`, `role`, `alive`, `health`, `mental`, `money`, `occupation`, `personality`, `bond`, `trust`, `conflict`, `romance`, `respect`, `relationType`, `tags`, `history`.

Поддерживаемые типы связей: `parent`, `grandparent`, `sibling`, `friend`, `best_friend`, `partner`, `ex_partner`, `spouse`, `child`, `coworker`, `mentor`, `enemy`, `acquaintance`. Внутренний `self` используется для узла игрока в семейном дереве.

Старые поля `family`, `relationship` и `children` пока сохраняются как совместимые проекции. Источником правды для новых систем считается `state.npcs`, а `GameRelationshipEngine.syncLegacy(state)` обновляет старые поля для экономики, итогов жизни и наследования.

Действия отношений описаны в `data/relationshipActions.js`, а применяются через `GameRelationshipActions.applyRelationshipAction(...)`. UI не меняет сложную семейную логику напрямую: кнопки только вызывают action/engine-функции.

Ежегодная симуляция вызывает `GameRelationshipEngine.yearlyRelationships(...)`: NPC стареют, здоровье и психика меняются, отношения дрейфуют под влиянием доверия, конфликта и стресса, а смерть NPC логируется в журнал.

## Образование И Карьера

Образование хранится в `state.education`, а совместимое поле `educationLevel` обновляется из него. Поддерживаемые уровни: дошкольное развитие, школа, среднее образование, колледж, университет, магистратура, курсы, самообразование и сертификаты.

Карьера хранится в `state.career`, а старые поля `profession`, `job`, `careerLevel` и `experience` остаются синхронными для отчетов, экономики и старых систем. Конкретные должности лежат в `data/careerEducation.js`; каждая содержит `id`, `title`, `industry`, `requirements`, зарплату, рост зарплаты, стресс, престиж, риск выгорания, требования к повышению, риск увольнения, рост навыков и `eventTags`.

`GameCareerEngine` отвечает за:

- проверку требований к должности;
- собеседование и получение работы;
- расчет зарплаты по городу, стране, опыту, образованию, навыкам, репутации и `careerLevel`;
- повышение, увольнение, понижение, карьерный перерыв, подработку, фриланс, портфолио, нетворкинг, наставника, премию и рабочие конфликты;
- ежегодные карьерные последствия: выгорание, премии и риск увольнения.

UI вкладок `Учеба` и `Карьера` только показывает данные и вызывает функции engine. Новые профессии и образовательные пути добавляются через data-каталоги, а не через UI.

## Экономика

Новая финансовая модель хранится в `state.economy`, а старые поля `personalMoney`, `debt`, `creditScore`, `taxableIncome`, `taxesPaid`, `taxDebt` и `assets` остаются совместимыми проекциями.

`state.economy` содержит `cash`, `bankBalance`, `yearlyIncome`, `yearlyExpenses`, `debt`, `loans`, `creditScore`, `taxBase`, `taxPaid`, `taxDebt`, `netWorth`, `assets`, `realEstate` и `financialHistory`.

`GameEconomyEngine` отвечает за:

- расчет капитала (`netWorth`);
- годовые расходы: жилье, еда и быт, дети, партнер и семья, медицина, транспорт, кредиты, налоги, образ жизни, страховка;
- доходы от зарплаты, фриланса, бизнеса, вкладов, акций, аренды недвижимости, помощи семьи и событий;
- кредиты: потребительский, образовательный, ипотека, бизнес-кредит, проценты, просрочка, штрафы и влияние на `creditScore`;
- активы: вклад, акции, пенсионный капитал, недвижимость и бизнес-активы;
- недвижимость: покупка, ипотека, содержание, рыночная переоценка, аренда и продажа;
- налоги по странам и годовую финансовую сводку.

Вкладка `Деньги` показывает данные из `state.economy`; вкладки `Дом` и `Активы` используют тот же engine для недвижимости и инвестиций.

## Здоровье

Новая модель здоровья хранится в `state.healthProfile`, а старые поля `health`, `mental`, `stress`, `energy` и навык `fitness` остаются совместимыми проекциями.

`state.healthProfile` содержит `health`, `mental`, `stress`, `energy`, `fitness`, `sleep`, `immunity`, `chronicConditions`, `injuries`, `activeConditions`, `habits`, `treatmentHistory` и `lastYearSummary`.

Игровые состояния лежат в `data/health.js`. Каждое состояние содержит `id`, `title`, `severity`, `minAge`, `riskFactors`, `effectsPerYear`, `treatmentOptions`, `deathRiskModifier`, `costModifier`, `eventTags` и внутренний `bucket` для активных состояний, травм или хронических состояний.

`GameHealthEngine` отвечает за:

- нормализацию старых сохранений и синхронизацию legacy-полей;
- расчет риска состояний по возрасту, стрессу, сну, иммунитету, форме и привычкам;
- добавление и снятие состояний;
- годовые эффекты состояний;
- лечение, стоимость лечения и скидку страховки;
- влияние здоровья на действия, карьеру, отношения, события и риск смерти.

Чтобы добавить новое состояние, добавьте объект через helper `condition(...)` в `data/health.js`. UI менять не нужно: вкладка `Здоровье` читает каталог и показывает варианты лечения из данных, а кнопки вызывают engine/action-функции.

## Право И Репутация

Правовой слой хранит совместимые поля `reputation`, `karma`, `criminalRecord`, а также нормализованные поля `legalStatus`, `fines`, `activeCases`, `pastCases`, `publicTrust`, `socialStanding` и `legalHistory`.

`data/legal.js` содержит статусы, правовые действия, абстрактные рискованные поступки и возможные исходы дел. Описания не являются инструкциями: это игровые ситуации с выбором и последствиями.

`GameLegalEngine` отвечает за:

- миграцию старых сохранений и вывод текущего `legalStatus`;
- штрафы, оплату штрафов и просрочки;
- открытые и закрытые дела;
- абстрактного юриста;
- восстановление репутации, волонтерство и публичное извинение;
- закрытие налоговых проблем;
- расчет правового риска по `traits.risk`, стрессу, давлению денег, социальному кругу, судимости и безопасности города;
- ограничения документов, поездок, работы и карьерные штрафы.

Правовые события лежат в `data/events/legal.js` и используют общий event engine. UI документов показывает статус и вызывает только action/engine-функции.

## Итоги Жизни И Достижения

Финальный итог считается через `GameLifeSummaryEngine`, а правила лежат в `data/lifeSummary.js`. Старые поля `lifeType` и `legacySnapshot` сохранены для совместимости, но новый источник подробной сводки - `state.lifeSummary`.

Итог включает возраст и причину смерти в игровой формулировке, капитал, семью, детей, партнеров, карьеру, образование, бизнес, здоровье, психику, счастье, известность, карму, репутацию, правовой статус, ключевые события и историю поколений.

Тип жизни выбирается по score rules из категорий: деньги, семья, карьера, образование, здоровье, счастье, репутация, карма, право, известность, бизнес и отношения. Новые типы добавляются в `lifeTypeRules`; UI менять не нужно.

Достижения описаны в `achievementRules` и сохраняются между жизнями в `localStorage`. Экран `Достижения` показывает открытые и еще не открытые достижения, а экран смерти показывает новые достижения именно этой жизни.

## Система Событий

События лежат в `data/events/` и подключаются как локальные JS data-модули. UI их не создает и не применяет: `ui/render.js` только показывает активное событие и вызывает `GameEvents.chooseEventOption(...)`.

Логика разделена так:

- `engine/events/eventConditions.js` - проверяет возраст, характеристики, флаги, отношения, детей, долги и другие условия.
- `engine/events/eventWeights.js` - считает вес события из `baseWeight`, `weightModifiers` и черт персонажа.
- `engine/events/eventEffects.js` - безопасно применяет эффекты к состоянию, деньгам, навыкам, отношениям, семье и риску.
- `engine/events/eventEngine.js` - выбирает событие, хранит active event как данные, применяет выбранную опцию и пишет журнал.

Чтобы добавить событие, добавьте объект в один из файлов `data/events/*.js`:

```js
{
  id: "unique_event_id",
  category: "school",
  title: "Название",
  description: "Ситуация",
  minAge: 7,
  maxAge: 17,
  baseWeight: 10,
  conditions: {
    minStats: { stress: 20 },
    maxStats: { health: 90 },
    requiredFlags: [],
    blockedFlags: []
  },
  weightModifiers: [{ stat: "stress", gte: 60, add: 8 }],
  options: [
    {
      id: "option_1",
      label: "Выбрать",
      description: "Краткое пояснение",
      effects: { health: 2, stress: -3, happiness: 4, money: -100 },
      resultText: "Что произошло.",
      risk: {
        chance: 0.15,
        effects: { stress: 5, reputation: -2 },
        resultText: "Дополнительное последствие."
      }
    }
  ]
}
```

Поддерживаемые условия: `minStats`, `maxStats`, `requiredFlags`, `blockedFlags`, `requiredState`, `minChildren`, `maxChildren`, `minMoney`, `maxDebt`, `hasRelationType`, `minNpcRelation`, `hasHealthCondition`, `noHealthCondition`, `hasLegalRestriction`, `noLegalRestriction`.

Поддерживаемые эффекты: базовые показатели `0-100`, здоровье (`sleep`, `immunity`, `fitness`, `addHealthCondition`, `removeHealthCondition`), правовой слой (`legalFine`, `legalCase`, `legalStatus`, `publicTrust`, `socialStanding`, `criminalRecord`), деньги (`money`, `familyMoney`, `debt`, `taxDebt`), навыки по id, `danger`, `flags`, `removeFlags`, отношения (`relationshipTrust`, `relationshipConflict`, `relationshipRomance`, `relationshipBond`, `relationshipStart`), семейные эффекты (`familyBond`, `childBond`, `npcTrust`, `npcBond`, `npcConflict`, `npcRespect`), опыт и карьерный уровень.

События лежат в data-слое, чтобы сценарии можно было расширять без правок UI и без разрастания годовой симуляции. Engine остается единственным местом, где проверяются условия, веса и последствия.
