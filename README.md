# Экономика жизни

Русскоязычный кнопочный симулятор жизни и личной экономики.

## Запуск

Откройте `index.html` двойным кликом в Finder на Mac.

## Суть

Вы начинаете с `0 лет` и нулем личных денег. Вокруг есть мама, папа, старшее поколение, семейный бюджет, страна и город рождения. Каждый год выбираются действия кнопками: детство, школа, друзья, здоровье, учеба, профессия, работа, переезд, отношения, дети, создание компании и управление деньгами.

Дополнительно симулируются навыки, характер, жилье, вещи, качество жизни, вклады, акции, пенсионный капитал, недвижимость, карьерное продвижение, фриланс, семейная помощь, годовые расходы, здоровье, психика, энергия, страховка, документы, налоги, визы и разрешение на работу.

В каждой стране используется своя валюта. Семья отображается как схематичное дерево поколений, а отношения включают романтику, доверие, конфликты, свидания, подарки, разговоры о будущем, общий бюджет, брак и детей.

Игра не имеет одного правильного финала: можно строить богатство, семью, карьеру, бизнес, здоровье, образование или баланс жизни.
